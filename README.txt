TESSAMORA — WEBSITE ADAPTADO

Estrutura:
- index.html: página inicial
- html/: roupas, acessórios, cosméticos, sobre e contacto
- css/style.css: estilos do website
- assets/Poppins/: fontes Poppins locais usadas pelo CSS

Matéria já estudada mantida:
- Estrutura HTML e tags semânticas já abordadas
- Parágrafos, imagens, links, títulos, div, span, formulários e inputs
- CSS básico, cores, fontes, margens, padding, dimensões, bordas e Flexbox

10 novidades combinadas:
1. HTML button
2. HTML label
3. HTML textarea
4. CSS Grid
5. Position
6. Media Queries simples
7. Pseudo-classes (:hover, :focus e :checked)
8. Transition
9. Transform
10. Variáveis CSS (:root e var)

Também foram preservados os degradês, os fundos, as imagens originais, as fontes e os efeitos hover.

Não foi adicionado JavaScript. Não foram usados keyframes nem animações contínuas.
As imagens continuam a ser carregadas dos mesmos endereços externos do projecto original.
A fonte Poppins é carregada da pasta assets/Poppins. Playfair Display é carregada do Google Fonts.

Para publicar no GitHub Pages, mantenha esta estrutura de pastas e envie o conteúdo desta pasta para a raiz do repositório.
